== Platform Compatibility


=== .NET Version Compatibility

The {sdk_dot_minor} {name-sdk} requires .NET 8 to be installed.
We recommend using the most recent long-term support (LTS) version of .NET.

TIP: Remember to keep your .NET installation up to date with the latest patches.
